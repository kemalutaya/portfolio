Case Study Highest Impact

Automating Administrative Draft Generation

3 hrs → 1 hr Daily schedule prep, before and afterEstimated, based on the previous manual process.
Problem
Three recurring daily tasks (sending physician schedules, notifying facilities, and preparing doctor-visit flyers) were all manual, repetitive, and error-prone: wrong doctor, wrong CC, wrong date, wrong attachment, typos.
Sending one doctor's schedule
Select the doctor and facility, and the macro fills recipient, CC, subject, body, and attachments Review every detail and send
2 steps · about 1 hour a day
Check patient count, per building Check status, per building Check insurance, per building Gather and attach the right files Draft the email, CC the right staff Repeat for every building, often 5+ per doctor
6 steps, repeated per building · about 3 hours a day
Three Automations Built
Physician Schedules
13 doctors, each assigned 1–10 facilities daily. Macro auto-matches the highlighted facility to the correct doctor's email, CCs the right RECA staff, and attaches the right files, eliminating wrong-doctor, wrong-CC, and wrong-attachment errors. Cut daily task time from 3 hours to 1.
Facility Notifications
50+ facilities, each with its own contact details. Macro auto-drafts each notification with the correct facility email, date, template, and attachments. Now sends 25+ notifications a day with zero mistakes.
Doctor-Visit Flyers
Same drafting logic, plus auto-renaming the facility name and visit date per doctor. Took the longest to build. Some facility names run long, and the flyer layout had to be adjusted to handle that without breaking.
My Contribution
Designed and built all three myself using Excel, Outlook, and Word macros: the tools already available on the remote desktop, since installing anything new required IT department approval. Each one collapses a multi-step manual process into a few clicks. I still review and send the output myself each time.
Result
Presented the workflow and it was approved for operational use.
